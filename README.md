# ORAN-CUDU-Dev: Technical Interview

Welcome, and thank you for taking the time to interview with us. This repository holds the hands-on exercises you'll work through during your technical interview. You'll work in your own editor and terminal.

## What to Expect

* **Assigned Exercises**: You'll be assigned specific exercises by your interviewer. 
* **Exercise Structure**: Each exercise is a folder containing a `README.md` (the task), starter files, and, where relevant, tests.
